# YINILOW

Curated thrift + home & electronics marketplace for Ghana, with live commerce.

## Product docs

- **[Product Requirements Document (PRD)](docs/PRD.md)** — scope, stack (Vert.x, React, PostgreSQL, Redis, WebSockets), architecture, and phased delivery

## Planned stack

| Layer | Technology |
|---|---|
| Backend | Eclipse Vert.x (Java) |
| Frontend | React.js (Vite) |
| Database | PostgreSQL |
| Cache / realtime fan-out | Redis |
| Realtime | WebSockets (Vert.x) |
| Media | S3-compatible object storage + third-party live video |

## Status

PRD drafted. Implementation not started.
